# Queens Match - Future Implementations

This file contains features from the assignment PDF and project ideas that should be saved for after the one-week MVP.

The MVP should not create placeholder services, unused database tables, or unfinished UI for these features. Add them only when the core mentoring flow is stable.

## Communication And Notifications
- WhatsApp reminders before scheduled meetings.
- Notifications to mentors when a new request arrives.
- Notifications to mentees when a mentor rejects or proposes times.
- Notifications to both sides when a meeting is scheduled.
- Automatic thank-you message to mentors after mentoring.

## Attendance And Follow-Up
- Ask both participants to confirm whether the meeting happened.
- If the meeting happened, send feedback forms.
- If the meeting did not happen, ask whether they want to schedule again.
- Allow another scheduling flow after missed meetings, if both sides agree.
- Remind users every two days if they did not submit feedback.

## Feedback
- Mentor feedback form.
- Mentee feedback form.
- Admin view for feedback results.
- Private notes for admin follow-up.
- Satisfaction metrics and summaries.

## Advanced Admin
- Calendar view of all scheduled meetings.
- Color-coded meeting statuses.
- Detailed meeting page.
- Detailed user page.
- Filters by mentor, mentee, status, and date.
- Alerts for meetings that did not happen.
- Alerts for meetings waiting too long for action.
- Alerts for users who did not submit feedback.
- Alert when a mentor completed more than ten mentoring meetings, so the admin can personally thank her.

## Search And Matching
- Search mentors by topic.
- Filter mentors by technology, company, experience, or meeting duration.
- Sort mentors by availability or activity.
- Recommend mentors based on mentee interests.
- Prevent mentor overload with capacity rules.

## Scheduling Improvements
- Calendar-style slot picker.
- Time zone support.
- Business-hours rules.
- Calendar export.
- Google Calendar integration.
- More flexible rescheduling rules.

## Deployment
- Deploy frontend and backend.
- Use a cloud database instead of local MongoDB.
- Add production environment variables.
- Add deployment documentation.
- Consider Vercel or another hosting service.

## AI Ideas
- Chatbot to help mentees choose a mentor.
- AI summary of mentor profile.
- AI-generated profile images or illustrations.
- AI helper for admin reports.

## Technical Improvements
- Automated tests for backend workflows.
- Frontend component tests.
- End-to-end demo tests.
- Better validation messages.
- Centralized error handling.
- Logging for important admin events.
- Improved accessibility checks.
- Better mobile layout.
